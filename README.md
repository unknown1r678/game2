# GALAXIAN - 2D Arcade Space Shooter

Python + Pygame (game) + MySQL (leaderboard). 7 levels, 4 enemy types, 2 bosses
(VORLON and SENTINEL), 3 ship upgrades, scoring and a top-10 leaderboard.
All graphics and sounds are generated by code - no image or audio files needed.

## Project structure

```
galaxian/
  galaxian.py        main game: player, enemies, bosses, levels, screens, HUD
  database.py        MySQL leaderboard (save score, top 10, error fallback)
  sounds.py          sound effects + music made from code
  setup.sql          creates the database and table
  requirements.txt   libraries to install
  README.md          this file
```

## Install and run

1. Install Python 3.8+ and MySQL Server.
2. Install the libraries:  `pip install -r requirements.txt`
3. Create the database (once):  `mysql -u root -p < setup.sql`
4. Open `database.py` and put your MySQL password in `DB_CONFIG`.
5. Run the game:  `python galaxian.py`

The game is fully playable even if MySQL is not set up: the leaderboard screen
then shows "Database not connected" and the game-over screen says the score was not saved.

## Controls

| Key | Action |
|-----|--------|
| Arrow keys / W A S D | Move (all four directions) |
| SPACE | Shoot (hold for continuous fire) |
| ESC | Pause (Resume / Restart / Main Menu) |
| UP / DOWN + ENTER | Menus |
| ENTER | Skip level briefing / upgrade / warning screens |
| L, M, ENTER | On Game Over / Victory: leaderboard, menu, play again |

## Features

* **Levels 1-7**, each with several waves. Enemies are introduced gradually
  and projectiles get 6% faster every level.
* **Enemies** - Self-Destruct (100 pts, locks on, accelerates, explodes), Laser Shooter
  (150, keeps distance, fires lasers), Golden Perk Mob (300, rare; drops +40 health, rapid fire 8 s,
  shield 6 s or +500 bonus - shown as floating text and on the HUD), Attack Tanker (500, slow,
  heavy spread shots, visible damage as health drops).
* **Kamikaze (Self-Destruct)** - drifts in, shakes for 0.6 s while it locks on (your warning), then
  dives. Its blast radius is 130 px (a faint circle and a shockwave ring show it).
* **Bosses** (each laser hit = 1 HP)
  * VORLON (level 5, 120 hits, 2500 pts): spread, aimed volley, charge->laser burst, charge->dive,
    and the **STRIKE** - it locks on and lunges at you for 65 damage. Faster and attacks up to 3x
    as often as it is hurt.
  * SENTINEL (level 7, 500 hits, 10000 pts): 3 phases. Heavy cannons, aimed fans, shells (phase 2+),
    bullet rings (phase 3), plus special moves: **bullet wall** with a gap, **rotating sweep beam**,
    **ground slam** with a shockwave (phase 2+) and **summoned kamikaze drones** (phase 3).
* **Ship upgrades** (kept for the whole run, each looks different):
  MK-I single laser -> **MK-II** (start of level 3) faster fire + stronger laser ->
  **MK-III** (after beating Vorlon) twin cannons + stronger laser + faster movement ->
  **MK-IV** (start of level 7) triple spread shot + rapid fire.
* **Scoring** - points per kill (given once, the moment the enemy dies), +1000 for finishing a
  level without losing a life. 3 lives, 100 health each.
* **Leaderboard** - top 10 (rank, username, points, levels) from the main menu and after
  Game Over / Victory. One row per username: a new run only replaces the old row if it scores more.
* Animated starfield, explosions, particles, screen shake (used sparingly), boss health bar,
  warning screens, separate normal and boss music.

### Design decisions (where the spec was open or contradictory)

* Boss HP counts **hits**: every laser hit takes 1 HP off a boss, whatever the ship. The ship's
  damage upgrade applies to normal enemies.
* Vorlon awards **2500** points (the spec lists both 500 and 2500).
* MK-IV is given at the **start of level 7** so it can be used against Sentinel
  (an upgrade after the final boss would never be used).
* Golden-mob rewards are applied immediately when it is destroyed.

## v2.1 changes

* **Kamikaze take turns** - after flying in they hover, each with a random delay (0.5 - 7 s). Only ONE can be in
  lock-on/dive at a time; Sentinel's summoned drones follow the same rule.
* **Perk pickups** (fly into them): `+` health, `R` rapid fire, `S` shield, `B` smart bomb (clears bullets, damages
  everything incl. -10 boss HP), `1UP` extra life. Dropped by enemies (12%, tankers 60%, golden mob always 2) and by
  bosses at every damage stage.
* **Arcade extras** - extra life every 5000 points (max 5 lives), +200 DIVE BONUS for shooting a kamikaze mid-dive.
* **Meaner bosses** - Vorlon: faster, attacks ~40% more often, new bullet-ring attack, shoots while moving when below 50%,
  quicker strike. Sentinel: shorter attack/special timers, faster movement, longer bullet walls, summons from phase 2
  (3 drones in phase 3), bullet rings from phase 2.

## Concepts used (for the viva)

**Python**: functions, classes and objects, **inheritance** (`Enemy` -> 4 enemy classes,
`Boss` -> `Vorlon`/`Sentinel`), lists of objects, dictionaries (levels, ship data), loops,
`random`, `math` (sin/cos for movement and aiming), string formatting, exception handling
(`try/except` for database and sound errors), modules (`import database`), game loop and
**delta time** (`dt`) so speed does not depend on the computer's frame rate, state machine
(`self.state` = menu / play / pause ...), **rectangle collision** (`colliderect`).

**Pygame**: `display`, `Surface`, `draw` shapes, `event` and `key.get_pressed`, `Clock`,
`mixer` (sound), `font`.

**SQL / MySQL**: `CREATE DATABASE`, `CREATE TABLE`, `PRIMARY KEY`, `AUTO_INCREMENT`,
`UNIQUE`, `INSERT`, `UPDATE`, `SELECT ... ORDER BY ... DESC LIMIT 10`, `NOW()`.
**Parameterized queries** (`%s` placeholders) stop SQL injection because the values are sent
separately from the SQL text. Python-MySQL connection: `connect()`, `cursor()`, `execute()`,
`fetchall()`, `commit()`, `close()`.
